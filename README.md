# COVID-19 Data Analysis in India

## 📌 Project Overview

This project analyzes COVID-19 data in India using Python.
The dataset contains information about confirmed cases,
recoveries, and deaths across different States and Union Territories.

## 🎯 Objectives

- Load and understand the COVID-19 dataset
- Clean and prepare the data
- Analyze confirmed COVID-19 cases
- Analyze deaths and recoveries
- Study daily COVID-19 trends
- Identify the most affected States/UTs
- Create meaningful visualizations

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## 📊 Visualizations

### 1. Daily COVID-19 Trends

Shows the trends of new confirmed cases, recoveries,
and deaths over time.

### 2. Top 10 States/UTs

Shows the States/UTs with the highest confirmed COVID-19 cases.

## 📁 Project Files

- covid_19_india.csv – COVID-19 dataset
- covid_analysis.py – Python analysis program
- daily_covid_trends.png – Daily trend graph
- top_10_states_cleaned.png – Top States/UTs graph

## ✅ Conclusion

The analysis shows the major trends in COVID-19 cases,
recoveries, and deaths in India and identifies the
States/UTs that experienced the highest number of confirmed cases.
